## 5. 비기능 요구사항

- **반응형**: 모바일(360px~), 태블릿(768px~), 데스크톱(1024px~), 와이드(1440px~) — 일반 페이지 기준. `/Ia` 관리 화면은 데스크톱 전용 (2026-11-25 결정, `/Guide`는 2026-11-25 폐지)
- **브라우저**: 최신 Chrome, Safari, Edge, Samsung Browser
- **접근성**: 이미지 `alt` 필수, 버튼과 링크는 키보드로 접근 가능
- **성능**: 이미지는 적절한 크기로 최적화, 첫 화면 3초 이내 로딩
